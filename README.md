<!-- GETTING STARTED -->
## Getting Started

### Prerequisites

* SDL3

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/Karrar-Hussein/chip8-emulator.git
   ```
1. Generate build files
   ```sh
   cmake -B build
   ```
1. Build
   ```sh
   cmake --build build
   ```
